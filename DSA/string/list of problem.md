## 3. How to Use This List

1. Solve the 8 Easy problems first, focusing on character operations and two-pointer patterns.
2. Then work through the 13 Medium problems, identifying the main pattern before coding.
3. For every problem, write the approach, C++ solution, dry run, time complexity, space complexity, and edge cases in its own Markdown note.
4. Track documentation separately from whether a problem has been accepted on LeetCode.
