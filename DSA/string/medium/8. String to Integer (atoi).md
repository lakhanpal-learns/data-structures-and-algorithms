# LeetCode 8 — String to Integer (atoi)

**Difficulty:** Medium  
**Topic:** Strings

## Problem
Implement `myAtoi(string s)` to convert a string into a 32-bit signed integer.

The conversion rules are:
1. Ignore leading spaces.
2. Read an optional `+` or `-` sign.
3. Convert consecutive digits into an integer.
4. Stop at the first non-digit character.
5. If no digits are read, return `0`.
6. Clamp the result to the signed 32-bit range: `[-2147483648, 2147483647]`.

## Approach: Parse and Check Overflow Before Multiplication

Maintain an index, a sign, and the number being built.

1. Skip leading spaces.
2. Read the optional sign.
3. Process digits while the current character is between `'0'` and `'9'`.
4. Convert a character to its numeric value using `s[i] - '0'`.
5. Before appending a digit with `num * 10 + digit`, check whether that operation would exceed the allowed limit.
6. Apply the sign and return the result.

### Why divide the limit by 10?

We append a digit using:

```cpp
num = num * 10 + digit;
```

To avoid overflowing before we can detect it, compare the current number with `limit / 10` first.

- If `num > limit / 10`, multiplying by 10 will already exceed the limit.
- If `num == limit / 10`, compare the new digit with `limit % 10`, which is the last allowed digit.

The positive limit is `2147483647), whose last digit is `7`. The negative magnitude can reach `2147483648), whose last digit is `8`. Therefore, the limit depends on the sign.

## C++ Solution

```cpp
#include <climits>
#include <string>
using namespace std;

class Solution {
public:
    int myAtoi(string s) {
        int n = s.size();
        int i = 0;

        // Step 1: Skip leading spaces
        while (i < n && s[i] == ' ') {
            i++;
        }

        // Step 2: Read the optional sign
        int sign = 1;

        if (i < n && (s[i] == '+' || s[i] == '-')) {
            if (s[i] == '-') {
                sign = -1;
            }
            i++;
        }

        // Step 3: Convert digits while checking overflow
        long long num = 0;
        long long limit = (sign == 1) ? INT_MAX : 2147483648LL;

        while (i < n && s[i] >= '0' && s[i] <= '9') {
            int digit = s[i] - '0';

            if (num > limit / 10 ||
                (num == limit / 10 && digit > limit % 10)) {
                return (sign == 1) ? INT_MAX : INT_MIN;
            }

            num = num * 10 + digit;
            i++;
        }

        // Step 4: Apply the sign
        return static_cast<int>(sign * num);
    }
};
```

## Complexity
- **Time:** `O(n)` — each character is visited at most once.
- **Extra space:** `O(1)` — only a fixed number of variables are used.

## Examples

| Input | Output | Explanation |
|---|---:|---|
| `"42"` | `42` | Normal conversion |
| `"   -42"` | `-42` | Skip spaces and read negative sign |
| `"4193 with words"` | `4193` | Stop at the first non-digit |
| `"words 987"` | `0` | No digits at the beginning |
| `"2147483648"` | `2147483647` | Clamp positive overflow |
| `"-91283472332"` | `-2147483648` | Clamp negative overflow |

## Important Edge Cases
- Leading zeroes are handled naturally by normal digit accumulation; no separate leading-zero flag is needed.
- A sign without digits, such as `"+"` or `"-"`, returns `0`.
- Do not skip non-digit characters to search for later digits. For example, `"words 987"` returns `0`.
- Check overflow before performing `num * 10 + digit`.
