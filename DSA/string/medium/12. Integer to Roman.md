# LeetCode 12 — Integer to Roman

**Difficulty:** Medium  
**Topic:** Strings / Greedy

## Problem
Given an integer `num`, convert it into a Roman numeral string.

## Roman Numeral Values

| Symbol | Value |
|---|---:|
| M | 1000 |
| D | 500 |
| C | 100 |
| L | 50 |
| X | 10 |
| V | 5 |
| I | 1 |

Special subtractive combinations:

| Symbol | Value |
|---|---:|
| CM | 900 |
| CD | 400 |
| XC | 90 |
| XL | 40 |
| IX | 9 |
| IV | 4 |

## Approach: Greedy

Use two parallel arrays:
- `values`: integer values in descending order, including the special combinations.
- `symbols`: corresponding Roman numeral strings.

Process the values from largest to smallest. While the current number is at least the current value:
1. Append the corresponding Roman symbol to the result.
2. Subtract that value from the number.

This greedily uses the largest Roman value that fits. Continue until the number becomes zero.

## C++ Solution

```cpp
class Solution {
public:
    string intToRoman(int num) {
        vector<int> values = {
            1000, 900, 500, 400,
            100, 90, 50, 40,
            10, 9, 5, 4, 1
        };

        vector<string> symbols = {
            "M", "CM", "D", "CD",
            "C", "XC", "L", "XL",
            "X", "IX", "V", "IV", "I"
        };

        string result = "";

        for (int i = 0; i < values.size(); i++) {
            while (num >= values[i]) {
                result += symbols[i];
                num -= values[i];
            }
        }

        return result;
    }
};
```

## Dry Run

Input: `num = 1994`

| Value | Symbol | Remaining number | Result |
|---:|---|---:|---|
| 1000 | M | 994 | M |
| 900 | CM | 94 | MCM |
| 90 | XC | 4 | MCMXC |
| 4 | IV | 0 | MCMXCIV |

Output: `"MCMXCIV"`

## Complexity
- **Time:** `O(1)` for the fixed Roman numeral value range (1–3999). The algorithm checks 13 entries and emits at most a fixed number of symbols.
- **Auxiliary space:** `O(1)` for the fixed lookup arrays. The output string is excluded.

## Important Detail
The special combinations (`CM`, `CD`, `XC`, `XL`, `IX`, `IV`) must be included in descending order. This lets the greedy algorithm handle subtractive notation naturally.
