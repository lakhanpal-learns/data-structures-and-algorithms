# 43. Multiply Strings

**LeetCode:** https://leetcode.com/problems/multiply-strings/

## Problem

Given two non-negative integers `num1` and `num2`, represented as strings, return their product as a string.

Do not convert the entire input strings into integers or use a built-in big-integer library.

## Approach: Grade-school multiplication

1. Create a result array of size `n + m`, where `n` and `m` are the lengths of the input strings.
2. Traverse both strings from right to left.
3. Convert each character digit to an integer using `num[i] - '0'`.
4. For each pair of digits, calculate:
   - `p1 = i + j`: position for the carry.
   - `p2 = i + j + 1`: position for the current digit.
   - `sum = digit1 * digit2 + result[p2]`.
5. Store the ones digit at `result[p2]` and add the carry to `result[p1]`.
6. Skip leading zeroes and convert the remaining digits into the answer string.

## C++ Solution

```cpp
class Solution {
public:
    string multiply(string num1, string num2) {
        if (num1 == "0" || num2 == "0") {
            return "0";
        }

        int n = num1.size();
        int m = num2.size();

        vector<int> result(n + m, 0);

        for (int i = n - 1; i >= 0; i--) {
            for (int j = m - 1; j >= 0; j--) {
                int digit1 = num1[i] - '0';
                int digit2 = num2[j] - '0';

                int p1 = i + j;
                int p2 = i + j + 1;

                int sum = digit1 * digit2 + result[p2];

                result[p2] = sum % 10;
                result[p1] += sum / 10;
            }
        }

        string answer;
        int index = 0;

        while (index < result.size() && result[index] == 0) {
            index++;
        }

        while (index < result.size()) {
            answer.push_back(result[index] + '0');
            index++;
        }

        return answer.empty() ? "0" : answer;
    }
};
```

## Complexity Analysis

- **Time Complexity:** `O(n * m)`, because every digit in `num1` is multiplied by every digit in `num2`.
- **Space Complexity:** `O(n + m)` for the result array and output string.

## Example

**Input:** `num1 = "12", num2 = "34"`

**Output:** `"408"`

The result array is built as `[0, 4, 0, 8]`; skipping the leading zero gives `"408"`.
