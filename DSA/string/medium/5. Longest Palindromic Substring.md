# LeetCode 5 — Longest Palindromic Substring

**Difficulty:** Medium  
**Topic:** Strings, Two Pointers

## Problem
Given a string `s`, return the longest substring of `s` that is a palindrome.

## Approach: Expand Around Center
A palindrome mirrors around its center. The center can be:
- One character (odd-length palindrome)
- A gap between two characters (even-length palindrome)

For every index `i`, expand from both center types:
1. Odd: `left = i`, `right = i`
2. Even: `left = i`, `right = i + 1`

While the pointers are in bounds and the characters match, calculate the current length and update the best result if it is longer. Then move outward.

## C++ Solution
```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        int start = 0;
        int maxLen = 0;

        for (int i = 0; i < n; i++) {
            // Odd-length palindrome
            int left = i;
            int right = i;

            while (left >= 0 && right < n &&
                   s[left] == s[right]) {
                int len = right - left + 1;

                if (len > maxLen) {
                    start = left;
                    maxLen = len;
                }

                left--;
                right++;
            }

            // Even-length palindrome
            left = i;
            right = i + 1;

            while (left >= 0 && right < n &&
                   s[left] == s[right]) {
                int len = right - left + 1;

                if (len > maxLen) {
                    start = left;
                    maxLen = len;
                }

                left--;
                right++;
            }
        }

        return s.substr(start, maxLen);
    }
};
```

## Complexity
- **Time:** `O(n^2)` — each possible center may expand across the string.
- **Extra space:** `O(1)` — uses only a fixed number of variables.

## Example
Input: `s = "cbbd"`  
Output: `"bb"`

The even center between the two `b` characters expands to `"bb"`. The next outward comparison is `c` vs `d`, which mismatches, so expansion stops.
