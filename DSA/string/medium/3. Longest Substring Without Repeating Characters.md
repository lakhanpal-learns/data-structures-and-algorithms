# LeetCode 3 — Longest Substring Without Repeating Characters

- **Difficulty:** Medium
- **Topic:** String, Sliding Window, Hash Set
- **Problem:** Find the length of the longest substring without repeating characters.

## Approach

1. Maintain a sliding window from `left` to `right`.
2. Store the characters currently in the window in an `unordered_set<char>`.
3. Expand the window by moving `right).
4. If the new character is already in the set, erase characters from the left and advance `left` until the duplicate is removed.
5. Insert the new character, calculate the current window length, and update the maximum.

## C++ Solution

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_set<char> window;
        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < s.size(); right++) {
            while (window.count(s[right])) {
                window.erase(s[left]);
                left++;
            }

            window.insert(s[right]);

            int currentLength = right - left + 1;
            maxLength = max(maxLength, currentLength);
        }

        return maxLength;
    }
};
```

## Dry Run

Input: `s = "abba"`

| right | Character | Window after handling duplicate | maxLength |
|---:|---|---|---:|
| 0 | a | a | 1 |
| 1 | b | ab | 2 |
| 2 | b | b | 2 |
| 3 | a | ba | 2 |

Output: `2`

## Key Details

- `window.count(ch)` returns 1 if the character exists in the set, otherwise 0.
- `window.erase(s[left])` removes the leftmost character from the current window.
- A substring is continuous, so the window cannot skip characters.
- The maximum is updated only after the window contains unique characters.

## Complexity

- **Time:** O(n) average; each character enters and leaves the set at most once.
- **Extra space:** O(min(n, character-set size)).
