# 17. Letter Combinations of a Phone Number

**Difficulty:** Medium  
**Topic:** String, Backtracking

## Problem

Given a string containing digits from `2` to `9`, return all possible letter combinations that the number could represent using the telephone keypad mapping.

## Approach: Backtracking

1. Map each digit to its corresponding letters.
2. Start at index `0` with an empty `current` string.
3. For the current digit, try every letter mapped to it.
4. Append the chosen letter to `current`.
5. Recursively process the next digit.
6. When `index == digits.size()`, the current combination is complete, so add it to `answer`.
7. After returning from recursion, remove the last character using `pop_back()` to undo the choice and try the next letter.

## C++ Solution

```cpp
class Solution {
public:
    void backtrack(string &digits,
                   int index,
                   unordered_map<char, vector<char>> &mp,
                   string &current,
                   vector<string> &answer)
    {
        // Base Case
        if (index == digits.size())
        {
            answer.push_back(current);
            return;
        }

        // Current digit
        char digit = digits[index];

        // Try every letter for this digit
        for (char ch : mp[digit])
        {
            // Choose
            current.push_back(ch);

            // Explore
            backtrack(digits, index + 1, mp, current, answer);

            // Undo (Backtrack)
            current.pop_back();
        }
    }

    vector<string> letterCombinations(string digits) {
        vector<string> answer;

        if (digits.empty())
            return answer;

        unordered_map<char, vector<char>> mp = {
            {'2', {'a', 'b', 'c'}},
            {'3', {'d', 'e', 'f'}},
            {'4', {'g', 'h', 'i'}},
            {'5', {'j', 'k', 'l'}},
            {'6', {'m', 'n', 'o'}},
            {'7', {'p', 'q', 'r', 's'}},
            {'8', {'t', 'u', 'v'}},
            {'9', {'w', 'x', 'y', 'z'}}
        };

        string current = "";

        backtrack(digits, 0, mp, current, answer);

        return answer;
    }
};
```

## Example

**Input:**
```
digits = "23"
```

**Output:**
```
["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

## Complexity Analysis

Let:
- `n` = number of input digits.
- `K` = total number of generated combinations.

- **Time Complexity:** `O(n × K)`, because each of the `K` combinations contains `n` characters and must be copied into the answer.
- **Auxiliary Space:** `O(n)` for the recursion depth and the `current` string, excluding the output.
- **Output Space:** `O(n × K)` to store all combinations.

Since each digit maps to at most four letters, `K ≤ 4^n`.

## Key Backtracking Operations

```cpp
current.push_back(ch);                  // Choose
backtrack(digits, index + 1, mp, current, answer); // Explore
current.pop_back();                     // Undo
```

The `pop_back()` call restores the previous partial combination so the next letter can be explored without keeping the previous choice.
