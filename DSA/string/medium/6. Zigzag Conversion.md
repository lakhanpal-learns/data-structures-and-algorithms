# LeetCode 6 — Zigzag Conversion

**Difficulty:** Medium  
**Topic:** Strings

## Problem
Given a string `s` and an integer `numRows`, write the characters in a zigzag pattern and return the string read row by row.

## Approach: Track the Current Row
Use a vector of strings, with one string for each row. For each character:
1. Append it to `rows[currentRow]`.
2. Reverse direction when reaching the top or bottom row.
3. Move the row pointer up or down.
4. Concatenate all row strings at the end.

This does not require a matrix because we only need to preserve the order of characters in each row.

## C++ Solution
```cpp
class Solution {
public:
    string convert(string s, int numRows) {
        if (numRows == 1 || numRows >= s.size()) {
            return s;
        }

        vector<string> rows(numRows);
        int currentRow = 0;
        bool goingDown = true;

        for (char ch : s) {
            rows[currentRow] += ch;

            if (currentRow == 0) {
                goingDown = true;
            } else if (currentRow == numRows - 1) {
                goingDown = false;
            }

            if (goingDown) {
                currentRow++;
            } else {
                currentRow--;
            }
        }

        string result;
        for (const string& row : rows) {
            result += row;
        }

        return result;
    }
};
```

## Complexity
- **Time:** `O(n)` — each character is placed once and then concatenated.
- **Extra space:** `O(n)` — the row strings store the characters.

## Example
Input: `s = "PAYPALISHIRING"`, `numRows = 3`  
Output: `"PAHNAPLSIIGYIR"`

Rows after placing all characters:
- Row 0: `PAHN`
- Row 1: `APLSIIG`
- Row 2: `YIR`

## Edge Case
When `numRows == 1` or `numRows >= s.length()`, the zigzag does not change the string, so return `s`.
