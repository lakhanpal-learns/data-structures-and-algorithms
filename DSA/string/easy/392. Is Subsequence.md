# LeetCode 392 — Is Subsequence

- **Difficulty:** Easy
- **Topic:** String, Two Pointers
- **Problem:** Determine whether `s` is a subsequence of `t`, preserving character order but allowing gaps.

## Approach

1. Use pointer `i` to track the next required character in `s`.
2. Use pointer `j` to scan through `t`.
3. If `s[i] == t[j]`, advance `i) because that character has been matched.
4. Advance `j` on every iteration.
5. If `i` reaches `s.size()`, every character in `s` was matched in order.

## C++ Solution

```cpp
class Solution {
public:
    bool isSubsequence(string s, string t) {
        int i = 0;
        int j = 0;

        while (i < s.size() && j < t.size()) {
            if (s[i] == t[j]) {
                i++;
            }
            j++;
        }

        return i == s.size();
    }
};
```

## Dry Run

Input: `s = "abc"`, `t = "ahbgdc"`

| i | j | Comparison | Action |
|---:|---:|---|---|
| 0 | 0 | a == a | Match; advance both |
| 1 | 1 | b != h | Advance only j |
| 1 | 2 | b == b | Match; advance both |
| 2 | 3 | c != g | Advance only j |
| 2 | 4 | c != d | Advance only j |
| 2 | 5 | c == c | Match; advance both |

At the end, `i = 3`, equal to `s.size()`, so return `true`.

## Key Details

- On a mismatch, move only `j`; keep `i) on the character still needed.
- On a match, move both pointers.
- If `s` is empty, it is a subsequence of any string, so the result is `true`.

## Complexity

- **Time:** O(|t|), each character of `t` is scanned at most once.
- **Extra space:** O(1).
