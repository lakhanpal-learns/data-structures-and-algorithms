# LeetCode 1768 — Merge Strings Alternately

**LeetCode:** https://leetcode.com/problems/merge-strings-alternately/  
**Difficulty:** Easy  
**Topic:** Strings, Two Pointers

## Problem

Given two strings, `word1` and `word2`, merge them by taking one character from `word1`, then one from `word2`, alternating until one string runs out. Append any remaining characters from the longer string.

### Examples

- `word1 = "abc", word2 = "pqr"` → `"apbqcr"`
- `word1 = "ab", word2 = "pqrs"` → `"apbqrs"`
- `word1 = "ab", word2 = "wxyz"` → `"awbxyz"`

## Approach

1. Create an empty result string and initialize indexes `i` and `j` to `0`.
2. While both indexes are within their strings, append one character from each string and increment both indexes.
3. Append any remaining characters from `word1`.
4. Append any remaining characters from `word2`.
5. Return the result.

## C++ Solution

```cpp
class Solution {
public:
    string mergeAlternately(string word1, string word2) {
        string result = "";
        int i = 0;
        int j = 0;

        // Merge characters alternately
        while (i < word1.size() && j < word2.size()) {
            result += word1[i];
            result += word2[j];

            i++;
            j++;
        }

        // Append remaining characters from word1
        while (i < word1.size()) {
            result += word1[i];
            i++;
        }

        // Append remaining characters from word2
        while (j < word2.size()) {
            result += word2[j];
            j++;
        }

        return result;
    }
};
```

## Dry Run

Input: `word1 = "ab", word2 = "wxyz"`

| Step | Action | Result |
|---|---|---|
| 1 | Append `a`, then `w` | `aw` |
| 2 | Append `b`, then `x` | `awbx` |
| 3 | `word1` is exhausted; append remaining `yz` | `awbxyz` |

## Edge Cases

- One string is empty: return the other string.
- Strings have equal lengths: alternate until both are exhausted.
- One string is longer: append its remaining characters in order.

## Complexity

Let `n` and `m` be the lengths of `word1` and `word2`.

- **Time:** `O(n + m)` — every input character is appended once.
- **Auxiliary space:** `O(1)` excluding the output string; the result itself uses `O(n + m)` space.
