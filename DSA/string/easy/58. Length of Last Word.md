# LeetCode 58 — Length of Last Word

**LeetCode:** https://leetcode.com/problems/length-of-last-word/  
**Difficulty:** Easy  
**Topic:** Strings

## Problem

Given a string `s` consisting of words and spaces, return the length of the last word. A word is a maximal substring consisting of non-space characters.

### Examples

- `s = "Hello World"` → `5`
- `s = "   fly me   to   the moon  "` → `4`
- `s = "luffy is still joyboy"` → `6`

## Approach: Scan from the end

1. Start at the last character.
2. Skip spaces at the end.
3. Count characters until reaching a space or the beginning of the string.
4. Return the count.

## C++ Solution

```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {
        int i = s.size() - 1;
        int count = 0;

        // Skip trailing spaces
        while (i >= 0 && s[i] == ' ') {
            i--;
        }

        // Count the last word
        while (i >= 0 && s[i] != ' ') {
            count++;
            i--;
        }

        return count;
    }
};
```

## Dry Run

Input: `"Hello World   "`

| Step | Action | Result |
|---|---|---|
| 1 | Skip trailing spaces | Index points to `d` |
| 2 | Count `d, l, r, o, W` moving backward | `count = 5` |
| 3 | Stop at the space before `World` | Return `5` |

## Why two loops?

The first loop skips trailing spaces; the second counts the last word. Keeping these steps separate makes the conditions simple and avoids counting spaces.

## Complexity

- **Time:** `O(n)` — in the worst case, each character is visited once.
- **Space:** `O(1)` — only two integer variables are used.
