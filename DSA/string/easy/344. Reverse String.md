# LeetCode 344 — Reverse String

- **Difficulty:** Easy
- **Topic:** String, Two Pointers
- **Problem:** Reverse the input character array in-place using O(1) extra space.

## Approach

1. Set `left` to the first index and `right` to the last index.
2. While `left < right`, swap the two characters.
3. Move `left` forward and `right` backward.
4. Stop when the pointers meet or cross.

## C++ Solution

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0;
        int right = static_cast<int>(s.size()) - 1;

        while (left < right) {
            swap(s[left], s[right]);
            left++;
            right--;
        }
    }
};
```

## Dry Run

Input: `['c', 'a', 't', 's']`

| Step | left | right | Action | Array |
|---|---:|---:|---|---|
| 1 | 0 | 3 | Swap `c` and `s` | `['s','a','t','c']` |
| 2 | 1 | 2 | Swap `a` and `t` | `['s','t','a','c']` |
| 3 | 2 | 1 | Pointers crossed; stop | `['s','t','a','c']` |

## Key Details

- `s.size()` returns `size_t`, an unsigned integer type.
- `static_cast<int>(s.size())` explicitly converts the size to `int), then subtracting 1 gives the last index.
- `left < right` avoids swapping the middle character with itself.
- The vector is modified directly; no extra array is created.

## Complexity

- **Time:** O(n), each character is involved in at most one swap.
- **Extra space:** O(1), only two index variables are used.
