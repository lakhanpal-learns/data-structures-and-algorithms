# LeetCode 125 — Valid Palindrome

**LeetCode:** https://leetcode.com/problems/valid-palindrome/  
**Difficulty:** Easy  
**Topic:** Strings, Two Pointers

## Problem

Given a string `s`, determine whether it is a palindrome after converting uppercase letters to lowercase and removing all non-alphanumeric characters.

### Examples

- `s = "A man, a plan, a canal: Panama"` → `true`
- `s = "race a car"` → `false`
- `s = " "` → `true`

## Approach: Two Pointers

1. Initialize `left` at the beginning and `right` at the end.
2. Skip non-alphanumeric characters from either side.
3. Compare valid characters after converting them to lowercase.
4. If they differ, return `false`.
5. If they match, move both pointers inward.
6. If the pointers meet or cross without a mismatch, return `true`.

## C++ Solution

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0;
        int right = static_cast<int>(s.size()) - 1;

        while (left < right) {
            if (!isalnum(static_cast<unsigned char>(s[left]))) {
                left++;
            } else if (!isalnum(static_cast<unsigned char>(s[right]))) {
                right--;
            } else {
                if (tolower(static_cast<unsigned char>(s[left])) !=
                    tolower(static_cast<unsigned char>(s[right]))) {
                    return false;
                }

                left++;
                right--;
            }
        }

        return true;
    }
};
```

## Dry Run

Input: `s = "ab_a"`

- Compare `a` at the left with `a` at the right — they match.
- Move both pointers inward.
- Skip the underscore because it is not alphanumeric.
- Compare `b` with itself — they match.
- No mismatch is found, so return `true`.

## Edge Cases

- Empty string or only punctuation/spaces → `true`
- Different valid characters → `false`
- Uppercase and lowercase versions of the same letter match.

## Complexity

- **Time:** `O(n)` — each pointer traverses the string at most once.
- **Space:** `O(1)` — only two pointer variables are used.
