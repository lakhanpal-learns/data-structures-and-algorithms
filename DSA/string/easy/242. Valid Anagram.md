# LeetCode 242 — Valid Anagram

**LeetCode:** https://leetcode.com/problems/valid-anagram/  
**Difficulty:** Easy  
**Topic:** Strings, Character Frequency

## Problem

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`; otherwise, return `false`.

Anagrams contain the same characters with the same frequencies, but the characters can appear in a different order.

### Examples

- `s = "anagram", t = "nagaram"` → `true`
- `s = "rat", t = "car"` → `false`
- `s = "aab", t = "abb"` → `false`

## Approach: Frequency Array

1. If the strings have different lengths, return `false`.
2. Create an array of 26 integers, initialized to zero.
3. Increase the count for each character in `s`.
4. Decrease the count for each character in `t`.
5. If every count is zero, the strings are anagrams. Any non-zero count means a character frequency differs.

This implementation assumes both strings contain only lowercase English letters (`a`–`z`), as permitted by the problem constraints.

## C++ Solution

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) {
            return false;
        }

        int freq[26] = {0};

        // Count characters in s
        for (int i = 0; i < s.size(); i++) {
            freq[s[i] - 'a']++;
        }

        // Subtract characters in t
        for (int i = 0; i < t.size(); i++) {
            freq[t[i] - 'a']--;
        }

        // Every frequency must balance to zero
        for (int i = 0; i < 26; i++) {
            if (freq[i] != 0) {
                return false;
            }
        }

        return true;
    }
};
```

## Why `s[i] - 'a'`?

Lowercase English letters have consecutive character codes. Subtracting the code for `'a'` maps letters to array indexes from 0 to 25:

- `'a' - 'a' = 0`
- `'b' - 'a' = 1`
- `'c' - 'a' = 2`
- `'z' - 'a' = 25`

So each letter uses its own slot in the frequency array.

## Dry Run

Input: `s = "aab", t = "abb"`

| Character | Count from `s` | Subtract count from `t` | Final balance |
|---|---:|---:|---:|
| `a` | 2 | 1 | +1 |
| `b` | 1 | 2 | -1 |

The balances are not all zero, so the function returns `false`.

## Complexity

- **Time:** `O(n)` — the strings are traversed and the fixed 26-entry array is checked.
- **Auxiliary space:** `O(1)` — the array always contains 26 integers.
