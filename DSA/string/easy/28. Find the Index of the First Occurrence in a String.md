# LeetCode 28 — Find the Index of the First Occurrence in a String

**Difficulty:** Easy  
**Topic:** Strings  
**LeetCode:** https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/

## Problem

Given two strings `haystack` and `needle`, return the index of the first occurrence of `needle` in `haystack`. Return `-1` if `needle` is not part of `haystack`. If `needle` is empty, return `0`.

## Examples

**Example 1**
```text
Input: haystack = "sadbutsad", needle = "sad"
Output: 0
```

**Example 2**
```text
Input: haystack = "hello", needle = "ll"
Output: 2
```

**Example 3**
```text
Input: haystack = "aaaaa", needle = "bba"
Output: -1
```

**Example 4**
```text
Input: haystack = "abcdef", needle = "def"
Output: 3
```

## Approach — Brute Force

1. Let `n` be the length of `haystack` and `m` be the length of `needle`.
2. Try each possible starting index `i` from `0` through `n - m`. Later positions do not have enough characters left to fit the needle.
3. For each start, set `j = 0` and compare `haystack[i + j]` with `needle[j]`.
4. Increase `j` while the characters match and `j < m`.
5. If `j == m`, every needle character matched, so return `i`.
6. If no start matches, return `-1`.

## C++ Solution

```cpp
class Solution {
public:
    int strStr(string haystack, string needle) {
        int n = haystack.size();
        int m = needle.size();

        for (int i = 0; i <= n - m; i++) {
            int j = 0;

            while (j < m && haystack[i + j] == needle[j]) {
                j++;
            }

            if (j == m) {
                return i;
            }
        }

        return -1;
    }
};
```

## Code Explanation

| Code | Purpose |
|---|---|
| `n - m` | Last valid starting index, because the full needle must fit. |
| `i` | Chooses a candidate starting position in `haystack`. |
| `j < m` | Stops once all needle characters have been checked. |
| `i + j` | Points to the haystack character aligned with `needle[j]`. |
| `j == m` | Means every character matched; return the starting index `i`. |
| `return -1` | No occurrence was found. |

## Dry Run

Input: `haystack = "abcdef"`, `needle = "def"`

| Start `i` | Compared substring | Result |
|---:|---|---|
| 0 | `"abc"` vs `"def"` | Mismatch |
| 1 | `"bcd"` vs `"def"` | Mismatch |
| 2 | `"cde"` vs `"def"` | Mismatch |
| 3 | `"def"` vs `"def"` | Full match; return `3` |

## Complexity

Let `n` be the length of `haystack` and `m` be the length of `needle`.

- **Time:** `O((n - m + 1) * m)`, commonly expressed as `O(n * m)` in the worst case.
- **Auxiliary space:** `O(1)`.

## Key Insight

The outer loop chooses where a match could begin; the inner loop checks the needle character by character. The last possible start is `n - m`.
