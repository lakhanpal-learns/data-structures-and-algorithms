# LeetCode 14 — Longest Common Prefix

**Difficulty:** Easy  
**Topic:** Strings  
**LeetCode:** https://leetcode.com/problems/longest-common-prefix/

## Problem

Given an array of strings, return the longest common prefix shared by every string. If there is no common prefix, return an empty string `""`.

### Examples

**Example 1**
```text
Input: strs = ["flower","flow","flight"]
Output: "fl"
```

**Example 2**
```text
Input: strs = ["dog","racecar","car"]
Output: ""
```

## Approach — Compare each string

1. Start by treating the first string as the current common prefix.
2. Compare that prefix with each remaining string, one at a time.
3. Use index `j` to compare characters from left to right.
4. Stop comparing when either string ends or the characters differ.
5. Keep only the matching part with `prefix.substr(0, j)`.
6. If the prefix becomes empty, return `""` immediately.
7. After checking every string, return the remaining prefix.

## C++ Solution

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        string prefix = strs[0];

        for (int i = 1; i < strs.size(); i++) {
            int j = 0;

            while (j < prefix.size() &&
                   j < strs[i].size() &&
                   prefix[j] == strs[i][j]) {
                j++;
            }

            prefix = prefix.substr(0, j);

            if (prefix.empty()) {
                return "";
            }
        }

        return prefix;
    }
};
```

## Dry Run 1

Input: `["flower", "flow", "flight"]`

| Step | Comparison | Result |
|---|---|---|
| Initialize | `prefix = "flower"` | Current prefix is `"flower"` |
| Compare with `"flow"` | `f=f, l=l, o=o, w=w` | Prefix becomes `"flow"` |
| Compare with `"flight"` | `f=f, l=l, o!=i` | Stop at index 2; prefix becomes `"fl"` |
| Finish | All strings checked | Return `"fl"` |

## Dry Run 2 — No Common Prefix

Input: `["dog", "racecar", "car"]`

1. Initialize `prefix = "dog"`.
2. Compare with `"racecar"` at index `j = 0`.
3. The first characters differ: `'d' != 'r'`. The `while` loop does not execute.
4. `prefix = prefix.substr(0, 0)`, so `prefix = ""`.
5. `prefix.empty()` is true, so return `""` immediately. The third string is not checked.

## Why the first two while conditions matter

```cpp
j < prefix.size() &&
j < strs[i].size() &&
prefix[j] == strs[i][j]
```

- `j < prefix.size()` ensures `j` is within the current prefix.
- `j < strs[i].size()` ensures `j` is within the string being compared.
- Only when both bounds checks pass do we compare the characters.
- C++ evaluates `&&` from left to right and short-circuits when a condition is false, so an invalid character access is avoided.

## Complexity

Let `n` be the number of strings and `m` the maximum string length.

- **Time:** `O(n * m)` in the worst case.
- **Auxiliary space:** `O(m)` for the prefix string; the returned string is excluded.

## Edge Cases

- No common starting character: `["dog", "racecar", "car"]` → `""`.
- One string: `["alone"]` → `"alone"`.
- One string is a prefix of another: `["flow", "flower"]` → `"flow"`.
- Identical strings: `["code", "code"]` → `"code"`.

## Common Mistakes

- Comparing characters at different positions instead of the same index.
- Forgetting that the strings may have different lengths.
- Accessing a character before checking both string bounds.
- Continuing after the common prefix becomes empty.
