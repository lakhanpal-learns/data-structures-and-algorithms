# 160. Intersection of Two Linked Lists

Given the heads of two singly linked-lists headA and headB, return the node at which the two lists intersect. If the two linked lists have no intersection at all, return null.

For example, the following two linked lists begin to intersect at node c1:

Input: intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
Output: Intersected at '8'



# algorithum 
Step 1:
Traverse List A and store every node pointer in a hash set.

Step 2:
Traverse List B.

Step 3:
For each node, check whether its pointer exists in the hash set.

Step 4:
If yes, return that node.

Step 5:
If no intersection is found, return nullptr.

# code 

class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
         <!--  store address  -->
        unordered_set<ListNode*> address;
        
<!--  traversing  -->

        ListNode* current = headA;
        while (current != nullptr)
        {
            
<!-- // store  -->

            address.insert(current);

            current = current->next;
        }

        // traversing second node 
        current = headB;

        while (current != nullptr)
        {
            // Check if current exists in the hash set
            if (address.find(current) != address.end())
                {
                    return current;
                }

            current = current->next;
        }

        return nullptr;

    }
};
