# 1863. Sum of All Subset XOR Totals

# problem 

## The Goal

Find every possible **subset** (sub-group) of the array, calculate the **XOR total** for each one, and add all those totals together.


### Simple Example: `nums = [1, 3]`

#### 1. Find all subsets

* `[]` (empty set)
* `[1]`
* `[3]`
* `[1, 3]`

#### 2. Calculate the XOR total for each

* `[]` $\rightarrow 0$
* `[1]` $\rightarrow 1$
* `[3]` $\rightarrow 3$
* `[1, 3]` $\rightarrow 1 \oplus 3 = 2$

#### 3. Add them all up

$$\text{Sum} = 0 + 1 + 3 + 2 = \mathbf{6}$$


# code 
class Solution {
public:

    void backtrack(vector<int>& nums, int index, int currentXor, int &answer)
    {
        // Base Case
        if (index == nums.size())
        {
            answer += currentXor;
            return;
        }

        // Choice 1: Include current element
        backtrack(nums, index + 1, currentXor ^ nums[index], answer);

        // Choice 2: Exclude current element
        backtrack(nums, index + 1, currentXor, answer);
    }

    int subsetXORSum(vector<int>& nums) {

        int answer = 0;

        backtrack(nums, 0, 0, answer);

        return answer;
    }
};
