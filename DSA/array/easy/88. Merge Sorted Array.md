# 88. Merge Sorted Array

## 1. Question

You are given two integer arrays, `nums1` and `nums2`, sorted in non-decreasing order, and two integers `m` and `n`, representing the number of valid elements in each array.

Merge `nums2` into `nums1` so that `nums1` becomes sorted. The first array has enough space at the end to hold all `m + n` elements. Modify `nums1` in-place.

**Example**

- Input: `nums1 = [1,2,3,0,0,0]`, `m = 3`, `nums2 = [2,5,6]`, `n = 3`
- Output: `[1,2,2,3,5,6]`

## 2. Solution Approach

Use three pointers and fill `nums1` from the end to avoid overwriting values that have not been processed.

| Step | What to do | Why |
|---|---|---|
| 1 | Set `i = m - 1`. | Points to the last valid element in `nums1`. |
| 2 | Set `j = n - 1`. | Points to the last element in `nums2`. |
| 3 | Set `k = m + n - 1`. | Points to the last available position in `nums1`. |
| 4 | While `j >= 0`, compare `nums1[i]` and `nums2[j]` when `i >= 0`. | The larger value belongs at the end of the merged array. |
| 5 | Put the larger value at `nums1[k]` and move its pointer backward. | Fills the array from right to left without overwriting unprocessed values. |
| 6 | Continue until all elements of `nums2` have been placed. | Any remaining valid elements in `nums1` are already in the correct positions. |

## 3. Code (C++)

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[k] = nums1[i];
                i--;
                k--;
            } else {
                nums1[k] = nums2[j];
                j--;
                k--;
            }
        }
    }
};
```

## 4. Code Explanation

| Code | Explanation |
|---|---|
| `int i = m - 1;` | Starts at the last valid element of `nums1`, ignoring its empty placeholder positions. |
| `int j = n - 1;` | Starts at the last element of `nums2`. |
| `int k = m + n - 1;` | Starts at the final position available in `nums1`. |
| `while (j >= 0)` | Continues until every element of `nums2` has been merged. |
| `i >= 0 && nums1[i] > nums2[j]` | Checks that `nums1` still has a valid element and whether it is larger than the current `nums2` element. |
| `nums1[k] = nums1[i];` | Places the larger `nums1` value at the current end position. |
| `nums1[k] = nums2[j];` | Otherwise, places the `nums2` value at the current end position. |
| `i--`, `j--`, `k--` | Moves the relevant source pointer and the destination pointer one position left. |

## 5. Dry Run

Input: `nums1 = [1,2,3,0,0,0]`, `m = 3`, `nums2 = [2,5,6]`, `n = 3`.

Start: `i = 2`, `j = 2`, `k = 5`.

| Compare | Action | nums1 after action |
|---|---|---|
| `3` vs `6` | Put `6` at index 5; decrement `j` and `k`. | `[1,2,3,0,0,6]` |
| `3` vs `5` | Put `5` at index 4; decrement `j` and `k`. | `[1,2,3,0,5,6]` |
| `3` vs `2` | Put `3` at index 3; decrement `i` and `k`. | `[1,2,3,3,5,6]` |
| `2` vs `2` | Condition is false, so put `2` from `nums2` at index 2. | `[1,2,2,3,5,6]` |
| `j = -1` | Stop; all elements from `nums2` are placed. | `[1,2,2,3,5,6]` |

**Output:** `[1,2,2,3,5,6]`

## 6. Key Insight to Remember

**Fill from the back.** Compare the largest remaining values and put the larger one at the last free position. This prevents overwriting valid values in `nums1`.

## 7. Complexity

| Type | Complexity | Reason |
|---|---|---|
| Time | `O(m + n)` | Each pointer moves only left, at most once per element. |
| Extra space | `O(1)` | The merge is done in-place without a separate result array. |

## 8. Important Edge Cases

- `nums2` is empty (`n = 0`): the loop does not run; `nums1` stays unchanged.
- `nums1` has no valid elements (`m = 0`): values from `nums2` are copied into `nums1`.
- Values are equal: the `else` branch takes the value from `nums2`; the result remains sorted.
