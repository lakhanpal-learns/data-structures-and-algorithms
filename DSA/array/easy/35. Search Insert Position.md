# LeetCode 35 — Search Insert Position

**Category:** Array / Easy  
**Pattern:** Binary search

## 1. Question

Given a sorted array of distinct integers and a target, return the target's index if it exists. Otherwise, return the index where it should be inserted to keep the array sorted.

**Example**

- Input: `nums = [1,3,5,6], target = 2`
- Output: `1`
- Explanation: Insert 2 at index 1 to keep the array sorted.

## 2. Solution approach

| Step | What to do | Why |
|---|---|---|
| 1 | Set `left = 0` and `right = nums.size() - 1`. | Search the full array. |
| 2 | Calculate `mid = left + (right - left) / 2`. | Find the middle safely. |
| 3 | If `nums[mid] == target`, return `mid`. | The target is found. |
| 4 | If `nums[mid] < target`, move `left = mid + 1`. | The target belongs to the right half. |
| 5 | Otherwise, move `right = mid - 1`. | The target belongs to the left half. |
| 6 | When the loop ends, return `left`. | It is the correct insertion position. |

## 3. C++ solution

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return left;
    }
};
```

## 4. Code explanation

| Code | Explanation |
|---|---|
| `left = 0`, `right = nums.size() - 1` | Define the current search range. |
| `while (left <= right)` | Continue while the range contains at least one index. |
| `mid = left + (right - left) / 2` | Find the middle index without adding the two bounds directly. |
| `nums[mid] == target` | Return immediately when the target is found. |
| `left = mid + 1` | Discard the middle and everything to its left. |
| `right = mid - 1` | Discard the middle and everything to its right. |
| `return left` | When the range becomes empty, `left` is where the target belongs. |

## 5. Dry run

Input: `nums = [1, 3, 5, 6], target = 2`

| left | right | mid | nums[mid] | Action |
|---:|---:|---:|---:|---|
| 0 | 3 | 1 | 3 | 3 > 2, so `right = 0` |
| 0 | 0 | 0 | 1 | 1 < 2, so `left = 1` |
| 1 | 0 | — | — | Loop ends; return `left = 1` |

## 6. Key insight to remember

**Binary search finds the target, and when it is absent, `left` ends at the insertion index.**

## 7. Complexity

- **Time:** O(log n)
- **Extra space:** O(1)

## 8. Edge cases

- Target already exists: `[1,3,5], target = 3` → `1`
- Insert at the beginning: `[2,4,6], target = 1` → `0`
- Insert at the end: `[2,4,6], target = 7` → `3`
- One element: `[5], target = 2` → `0`
