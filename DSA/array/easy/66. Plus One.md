# LeetCode 66 — Plus One

**Category:** Array / Easy  
**Pattern:** Array traversal, carry

## 1. Question

You are given a non-empty array `digits` representing a non-negative integer. Each element is one digit, ordered from most significant to least significant. Add one to the integer and return the resulting array of digits.

**Example**

- Input: `digits = [1,2,9]`
- Output: `[1,3,0]`
- Explanation: 129 + 1 = 130.

## 2. Solution approach

| Step | What to do | Why |
|---|---|---|
| 1 | Start from the last digit. | The ones place changes first. |
| 2 | If the digit is less than 9, increase it and return. | No carry is needed. |
| 3 | If the digit is 9, change it to 0 and continue left. | Adding one creates a carry. |
| 4 | If every digit was 9, insert 1 at the beginning. | The number needs one extra digit. |

## 3. C++ solution

```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        for (int i = digits.size() - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits;
            }

            digits[i] = 0;
        }

        digits.insert(digits.begin(), 1);
        return digits;
    }
};
```

## 4. Code explanation

| Code | Explanation |
|---|---|
| `int i = digits.size() - 1` | Begin at the last index. |
| `digits[i] < 9` | Check whether adding one avoids a carry. |
| `digits[i]++` | Increase the digit and finish. |
| `digits[i] = 0` | A 9 becomes 0, so carry continues to the left. |
| `digits.insert(digits.begin(), 1)` | If all digits were 9, add a new leading 1. |

## 5. Dry run

Input: `[1, 2, 9]`

| Index | Current digit | Action | Array |
|---:|---:|---|---|
| 2 | 9 | Set to 0; carry continues | `[1, 2, 0]` |
| 1 | 2 | Increase to 3; return | `[1, 3, 0]` |

Input: `[9, 9]` → both digits become 0, then insert 1 → `[1, 0, 0]`.

## 6. Key insight to remember

**Start from the right. A 9 becomes 0 and passes the carry left; the first non-9 digit increases and stops the process.**

## 7. Complexity

- **Time:** O(n) worst case.
- **Extra space:** O(1) auxiliary space, excluding the output growth when a new leading digit is inserted.

## 8. Edge cases

- `[1, 2, 3]` → `[1, 2, 4]`
- `[1, 2, 9]` → `[1, 3, 0]`
- `[9, 9, 9]` → `[1, 0, 0, 0]`
