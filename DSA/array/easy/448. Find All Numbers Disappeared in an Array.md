# 448. Find All Numbers Disappeared in an Array

## 1. Question

Given an integer array `nums` of length `n`, where every number is in the range `[1, n]`, return all numbers in the range `[1, n]` that do not appear in `nums`.

**Example**

- Input: `nums = [1, 1, 3, 4, 4]`
- Output: `[2, 5]`

## 2. Solution Approach

Use a boolean checklist to remember which numbers appear.

| Step | What to do | Why |
|---|---|---|
| 1 | Find `n = nums.size()`. | The possible numbers are from `1` to `n`. |
| 2 | Create `seen` of size `n + 1`, initialized to `false`. | Index `0` stays unused, so number `x` can be stored at index `x`. |
| 3 | Traverse `nums` and set `seen[x] = true`. | Mark every number that appears. Duplicates are harmless. |
| 4 | Check indices from `1` through `n`. | These are all the numbers that should appear. |
| 5 | If `seen[i]` is `false`, add `i` to the answer. | That number never appeared in `nums`. |
| 6 | Return the answer. | It contains every missing number. |

## 3. Code (C++)

```cpp
class Solution {
public:
    vector<int> findDisappearedNumbers(vector<int>& nums) {
        int n = nums.size();
        vector<bool> seen(n + 1, false);

        for (int x : nums) {
            seen[x] = true;
        }

        vector<int> ans;

        for (int i = 1; i <= n; i++) {
            if (seen[i] == false) {
                ans.push_back(i);
            }
        }

        return ans;
    }
};
```

## 4. Code Explanation

| Code | Explanation |
|---|---|
| `int n = nums.size();` | Stores the length of the input array. |
| `vector<bool> seen(n + 1, false);` | Creates a checklist, initially marking every number as missing. |
| `for (int x : nums)` | Visits each value in the input array. |
| `seen[x] = true;` | Marks the value `x` as present. |
| `vector<int> ans;` | Creates the list for missing numbers. |
| `for (int i = 1; i <= n; i++)` | Checks every expected number from `1` to `n`. |
| `if (seen[i] == false)` | Checks whether number `i` never appeared. |
| `ans.push_back(i);` | Adds the missing number to the answer. |
| `return ans;` | Returns all missing numbers. |

## 5. Dry Run

Input: `nums = [1, 1, 3, 4, 4]`, so `n = 5`.

| Number checked in input | Checklist update |
|---:|---|
| 1 | `seen[1] = true` |
| 1 | `seen[1] = true` again; no problem |
| 3 | `seen[3] = true` |
| 4 | `seen[4] = true` |
| 4 | `seen[4] = true` again; no problem |

After marking, the checklist for numbers `1` to `5` is:

| Number | Seen? | Action |
|---:|---|---|
| 1 | `true` | Skip |
| 2 | `false` | Add `2` |
| 3 | `true` | Skip |
| 4 | `true` | Skip |
| 5 | `false` | Add `5` |

**Output:** `[2, 5]`

## 6. Key Insight to Remember

**Mark first, check later.** Use each value as an index to mark that it exists. Then, any unmarked number from `1` to `n` is missing.

## 7. Complexity

| Type | Complexity | Reason |
|---|---|---|
| Time | `O(n)` | One pass marks values and one pass checks the checklist. |
| Extra space | `O(n)` | The boolean checklist uses `n + 1` positions. |
