# LeetCode 268 — Missing Number

**Category:** Array / Easy  
**Pattern:** Mathematics, array traversal

## 1. Question

Given an array `nums` containing `n` distinct numbers from the range `[0, n]`, return the one number in that range that is missing.

**Example**

- Input: `nums = [3,0,1]`
- Output: `2`
- Explanation: The range is `[0, 3]`; the number 2 is missing.

## 2. Solution approach — Sum formula

| Step | What to do | Why |
|---|---|---|
| 1 | Let `n = nums.size()`. | The complete range contains `n + 1` numbers. |
| 2 | Calculate expected sum: `n * (n + 1) / 2`. | This is the sum of all numbers from 0 to n. |
| 3 | Calculate the sum of the given array. | Add all numbers that are present. |
| 4 | Return expected sum minus actual sum. | The difference is the missing number. |

## 3. C++ solution

```cpp
class Solution {
public:
    int missingNumber(vector<int>& nums) {
        int n = nums.size();
        int expectedSum = n * (n + 1) / 2;
        int actualSum = 0;

        for (int num : nums) {
            actualSum += num;
        }

        return expectedSum - actualSum;
    }
};
```

## 4. Code explanation

| Code | Explanation |
|---|---|
| `int n = nums.size()` | Find the array length and the upper bound of the range. |
| `n * (n + 1) / 2` | Calculate the sum of numbers from 0 through n. |
| `int actualSum = 0` | Start the sum of present numbers at zero. |
| `for (int num : nums)` | Visit each number in the array. |
| `actualSum += num` | Add the current number to the actual sum. |
| `return expectedSum - actualSum` | The difference gives the missing number. |

## 5. Dry run

Input: `nums = [3,0,1]`

| Calculation | Value |
|---|---:|
| `n` | 3 |
| Expected sum: `3 * (3 + 1) / 2` | 6 |
| Actual sum: `3 + 0 + 1` | 4 |
| Missing number: `6 - 4` | 2 |

## 6. Key insight to remember

**Expected sum − actual sum = missing number.** Use the formula `n * (n + 1) / 2` for the complete range from 0 to n.

## 7. Complexity

- **Time:** O(n)
- **Extra space:** O(1)

## 8. Edge cases

- Missing zero: `[3,0,1]` is not this case; for example `[1,2]` → `0`.
- Missing last number: `[0,1]` → `2`.
- Single element: `[0]` → `1`.
