# LeetCode 27 — Remove Element

**Category:** Array / Easy  
**Pattern:** Two pointers, in-place overwrite

## 1. Question

Given an integer array `nums` and an integer `val`, remove every occurrence of `val` in-place. Return the number of elements that are not equal to `val`. The order of the remaining elements can be kept.

The first `k` elements of `nums` must contain the values that are not equal to `val`.

**Example**

- Input: `nums = [3,2,2,3], val = 3`
- Output: `2`
- The first two elements become `[2,2]`.

## 2. Solution approach

| Step | What to do | Why |
|---|---|---|
| 1 | Create a write index `k = 0`. | It marks where the next kept value belongs. |
| 2 | Scan every value in the array. | Each value must be checked once. |
| 3 | If the value is not `val`, write it to `nums[k]`. | Keep only values we want. |
| 4 | Increase `k` after writing a kept value. | Move the next write position forward. |
| 5 | Return `k`. | It is the count of remaining values. |

## 3. C++ solution

```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int k = 0;

        for (int i = 0; i < nums.size(); i++) {
            if (nums[i] != val) {
                nums[k] = nums[i];
                k++;
            }
        }

        return k;
    }
};
```

## 4. Code explanation

| Code | Explanation |
|---|---|
| `int k = 0` | Start the write position at the beginning. |
| `for (int i = 0; i < nums.size(); i++)` | Read every original array position. |
| `nums[i] != val` | Check whether the current value should be kept. |
| `nums[k] = nums[i]` | Copy a kept value to the next valid position. |
| `k++` | Increase the count and next write position. |
| `return k` | Return the length of the valid prefix. |

## 5. Dry run

Input: `nums = [3,2,2,3], val = 3`

| Read index `i` | Value | Action | `k` after action | Valid prefix |
|---:|---:|---|---:|---|
| 0 | 3 | Skip | 0 | `[]` |
| 1 | 2 | Write to `nums[0]` | 1 | `[2]` |
| 2 | 2 | Write to `nums[1]` | 2 | `[2,2]` |
| 3 | 3 | Skip | 2 | `[2,2]` |

Return `2`. Only the first `k` positions matter; values after that prefix can be ignored.

## 6. Key insight to remember

**Read with `i`, write with `k`. Copy only values you want to keep, so no extra array is needed.**

## 7. Complexity

- **Time:** O(n)
- **Extra space:** O(1)

## 8. Edge cases

- All values equal `val` → return `0`.
- No values equal `val` → return the original array length.
- Empty array → return `0`.
