# 26. Remove Duplicates from Sorted Array
Problem: Remove Duplicates from Sorted Array (LeetCode 26)
1. What does the problem ask?
You are given a sorted array containing duplicate numbers. You must remove the duplicates in-place so that each number appears only once.
Example:
nums = [0,0,1,1,1,2,2,3,3,4]


After removing duplicates, the beginning of the array must contain:
[0,1,2,3,4]


You must return 5, because there are five unique numbers.


2. What does "in-place" mean?
You must modify the original array. You cannot create another array to store the unique elements.
You can overwrite existing elements.

3. What does the function return?
It returns k, the number of unique elements.
The first k elements must contain the unique values in sorted order. Anything after those elements doesn't matter.

4. What is the important observation?
Because the array is sorted, duplicate numbers are next to each other.

# obseration 
> comparing
> counting 
> replacing 


# code 
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int k = 1;

        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] != nums[k - 1]) {
                nums[k] = nums[i];
                k++;
            }
        }

        return k;
    }
};
