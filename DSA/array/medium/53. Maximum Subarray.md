# 53. Maximum Subarray

**LeetCode:** https://leetcode.com/problems/maximum-subarray/  
**Difficulty:** Medium  
**Pattern:** Kadane's algorithm

## Question

Given an integer array `nums`, find the contiguous subarray with the largest sum and return that sum.

A subarray must contain at least one element.

**Example**

```text
Input:  nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output: 6
```

The maximum-sum subarray is `[4, -1, 2, 1]`, and its sum is `4 + (-1) + 2 + 1 = 6`.

## Solution Approach

Use **Kadane's algorithm** to track the best subarray ending at the current index and the best sum found anywhere so far.

| Variable | Meaning |
|---|---|
| `currentSum` | The maximum sum of a subarray that must end at the current index. |
| `maxSum` | The largest subarray sum found anywhere so far. |

At each number, make a choice: start a new subarray at this number, or extend the previous subarray.

`currentSum = max(nums[i], currentSum + nums[i])`

Then update the overall best result:

`maxSum = max(currentSum, maxSum)`

## C++ Code

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int currentSum = nums[0];
        int maxSum = nums[0];

        for (int i = 1; i < nums.size(); i++) {
            // Start a new subarray or extend the previous one
            currentSum = max(nums[i], currentSum + nums[i]);

            // Record the best sum found so far
            maxSum = max(currentSum, maxSum);
        }

        return maxSum;
    }
};
```

## Code Explanation

| Code | Explanation |
|---|---|
| `int currentSum = nums[0];` | Starts with the first element because a valid subarray must contain at least one number. |
| `int maxSum = nums[0];` | The first element is also the best sum seen so far initially. |
| `currentSum = max(nums[i], currentSum + nums[i]);` | Either start fresh at `nums[i]` or add it to the previous subarray. Keep whichever gives the larger sum. |
| `maxSum = max(currentSum, maxSum);` | Compare the best subarray ending here with the best answer from earlier indices. |
| `return maxSum;` | Returns the largest contiguous-subarray sum. |

**Important order:** Update `currentSum` first, then compare it with `maxSum`. The overall answer must consider the best subarray ending at the current index.

## Dry Run

Input: `nums = [-2, 1, -3, 4, -1, 2, 1]`

| Index | `nums[i]` | `currentSum` calculation | New `currentSum` | New `maxSum` |
|---:|---:|---|---:|---:|
| 0 | -2 | Initialize | -2 | -2 |
| 1 | 1 | `max(1, -2 + 1)` | 1 | 1 |
| 2 | -3 | `max(-3, 1 - 3)` | -2 | 1 |
| 3 | 4 | `max(4, -2 + 4)` | 4 | 4 |
| 4 | -1 | `max(-1, 4 - 1)` | 3 | 4 |
| 5 | 2 | `max(2, 3 + 2)` | 5 | 5 |
| 6 | 1 | `max(1, 5 + 1)` | 6 | 6 |

**Final output:** `6`  
**Maximum-sum subarray:** `[4, -1, 2, 1]`

## Key Insight to Remember

**If the previous running sum hurts the current number, drop it and start fresh. Otherwise, extend the current subarray.** Keep a separate variable to remember the best sum found anywhere.

## Complexity

- **Time:** `O(n)` — one pass through the array.
- **Auxiliary space:** `O(1)` — only two running-sum variables are used.

## Edge Cases

- **All negative numbers:** Initializing both variables with `nums[0]` ensures the answer is the largest (least negative) element, not zero.
- **One element:** The answer is that element.
- **Mixed positive and negative numbers:** Kadane's algorithm decides when to extend or restart the subarray.
