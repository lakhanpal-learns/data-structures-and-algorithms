# 238. Product of Array Except Self

**LeetCode:** https://leetcode.com/problems/product-of-array-except-self/  
**Difficulty:** Medium  
**Pattern:** Prefix and suffix products

## Question

Given an integer array `nums`, return an array `answer` where `answer[i]` is equal to the product of all elements of `nums` except `nums[i]`.

The solution must run in **O(n)** time and must not use division.

**Example**

```text
Input:  nums = [2, 3, 4, 5]
Output: [60, 40, 30, 24]
```

For example, the answer for `4` is `2 × 3 × 5 = 30`.

## Solution Approach

The product of all elements except the current one can be split into two parts:

`answer[i] = product of elements to the left × product of elements to the right`

| Step | What to do | Why it works |
|---|---|---|
| 1. Initialize | Create `answer(n, 1)` | Stores the result for each index. |
| 2. Left pass | Move left to right, store `leftProduct` in `answer[i]`, then multiply `leftProduct` by `nums[i]`. | Each position stores the product of all elements before it. |
| 3. Right pass | Move right to left, multiply `answer[i]` by `rightProduct`, then multiply `rightProduct` by `nums[i]`. | Completes each answer using the product of all elements after it. |
| 4. Return | Return `answer`. | Every position now contains the product of all other elements. |

## C++ Code

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> answer(n, 1);

        // First pass: store products of elements to the left
        int leftProduct = 1;

        for (int i = 0; i < n; i++) {
            answer[i] = leftProduct;
            leftProduct *= nums[i];
        }

        // Second pass: multiply by products of elements to the right
        int rightProduct = 1;

        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= rightProduct;
            rightProduct *= nums[i];
        }

        return answer;
    }
};
```

## Code Explanation

| Code | Explanation |
|---|---|
| `vector<int> answer(n, 1);` | Creates an output array of size `n`, initialized with 1. |
| `int leftProduct = 1;` | Starts the left-side product at 1 because the first element has nothing to its left. |
| `answer[i] = leftProduct;` | Stores the product of all elements before the current index. |
| `leftProduct *= nums[i];` | Adds the current number to the running product for the next index. |
| `int rightProduct = 1;` | Starts the right-side product at 1 because the last element has nothing to its right. |
| `answer[i] *= rightProduct;` | Combines the stored left product with the right-side product to complete the answer. |
| `rightProduct *= nums[i];` | Adds the current number to the running right product for the next index to the left. |
| `return answer;` | Returns the completed array. |

**Important order:** In both passes, store or combine the product **before** multiplying the running product by the current element. This excludes the current element from its own answer.

## Dry Run

Input: `nums = [2, 3, 4, 5]`

### First pass: left products

| Index | Current number | `leftProduct` before | Stored in `answer[i]` | `leftProduct` after |
|---:|---:|---:|---:|---:|
| 0 | 2 | 1 | 1 | 2 |
| 1 | 3 | 2 | 2 | 6 |
| 2 | 4 | 6 | 6 | 24 |
| 3 | 5 | 24 | 24 | 120 |

After the first pass: `answer = [1, 2, 6, 24]`

### Second pass: right products

| Index | Current number | `rightProduct` before | Answer calculation | Updated answer | `rightProduct` after |
|---:|---:|---:|---|---:|---:|
| 3 | 5 | 1 | 24 × 1 | 24 | 5 |
| 2 | 4 | 5 | 6 × 5 | 30 | 20 |
| 1 | 3 | 20 | 2 × 20 | 40 | 60 |
| 0 | 2 | 60 | 1 × 60 | 60 | 120 |

**Final output:** `[60, 40, 30, 24]`

## Key Insight to Remember

**Store left products first; walk backward to multiply in right products.** Two passes avoid division and handle zeros naturally.

## Complexity

- **Time:** `O(n)` — two passes through the array.
- **Auxiliary space:** `O(1)` beyond the output array.
- **Output space:** `O(n)` for the returned array.

## Edge Cases

- **One zero:** Only the position containing zero gets the product of the non-zero elements; all other positions become zero.
- **Two or more zeros:** Every answer is zero.
- **No zeros:** The same two-pass algorithm works without any special handling.
- **Negative values:** Multiplication naturally handles negative numbers.
