# 15. 3Sum

**LeetCode:** https://leetcode.com/problems/3sum/  
**Difficulty:** Medium  
**Pattern:** Sorting + Two Pointers

## Question

Given an integer array `num`, return all unique triplets `[num[i], num[j], num[k]]` such that the three values add up to zero.

The same triplet must not appear more than once in the answer.

**Example**

```text
Input:  num = [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]
```

## Solution Approach

Sort the array first. Then, for each index `i`, keep `num[i]` fixed and use two pointers to find two other values that make the total sum zero.

- `i` chooses the first value.
- `j` starts just after `i`.
- `k` starts at the end of the array.
- If the sum is too small, move `j right to increase it.
- If the sum is too large, move `k left to decrease it.
- If the sum is zero, save the triplet, move both pointers, and skip duplicate values.

Sorting makes the pointer movement possible and places duplicate values next to each other.

## C++ Code

```cpp
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& num) {
        vector<vector<int>> ans;
        sort(num.begin(), num.end());

        for (int i = 0; i < num.size(); i++) {
            if (i > 0 && num[i] == num[i - 1]) continue;

            int j = i + 1;
            int k = num.size() - 1;

            while (j < k) {
                int sum = num[i] + num[j] + num[k];

                if (sum < 0) {
                    j++;
                } else if (sum > 0) {
                    k--;
                } else {
                    vector<int> temp = {num[i], num[j], num[k]};
                    ans.push_back(temp);
                    j++;
                    k--;

                    while (j < k && num[j] == num[j - 1]) j++;
                    while (j < k && num[k] == num[k + 1]) k--;
                }
            }
        }

        return ans;
    }
};
```

## Code Explanation

| Code | Explanation |
|---|---|
| `vector<vector<int>> ans;` | Stores all unique triplets found. |
| `sort(num.begin(), num.end());` | Sorts the numbers so pointer movement is predictable and duplicates are adjacent. |
| `for (int i = 0; i < num.size(); i++)` | Fixes one number as the first value of the triplet. |
| `if (i > 0 && num[i] == num[i - 1]) continue;` | Skips a repeated first value to avoid producing the same triplets again. |
| `int j = i + 1;` | Starts the left pointer just after the fixed number. |
| `int k = num.size() - 1;` | Starts the right pointer at the last index. |
| `int sum = num[i] + num[j] + num[k];` | Calculates the sum of the current three values. |
| `if (sum < 0) j++;` | The sum is too small, so move to a larger value on the left. |
| `else if (sum > 0) k--;` | The sum is too large, so move to a smaller value on the right. |
| `ans.push_back(temp);` | Saves a triplet when its sum equals zero. |
| `j++; k--;` | Moves both pointers inward to continue searching for other pairs. |
| The two duplicate-skipping `while` loops | Skip repeated left and right values after finding a valid triplet. |
| `return ans;` | Returns all unique triplets. |

## Complete Logic in Plain English

1. Sort all the numbers from smallest to largest.
2. Start a loop that chooses each number as the first number of a possible triplet.
3. If this first number is the same as the previous one, skip it because we have already searched for triplets starting with that value.
4. Put the left pointer just after the first number and the right pointer at the last number.
5. Add the values at the first, left, and right positions.
6. If their sum is less than zero, it is too small. Move the left pointer one step right to try a larger number.
7. If their sum is greater than zero, it is too large. Move the right pointer one step left to try a smaller number.
8. If their sum equals zero, save those three numbers as a valid triplet.
9. After saving a triplet, move both pointers inward and skip any repeated left or right values so the same triplet is not added again.
10. Continue until the left and right pointers meet or cross.
11. Repeat with the next non-duplicate first number.
12. Return the list of unique triplets.

### Memory Trick

**Sort → Fix one number → Two pointers → Sum too small: move left pointer right → Sum too large: move right pointer left → Sum zero: save and skip duplicates.**

## Dry Run

Input: `num = [-1, 0, 1, 2, -1, -4]`

After sorting: `[-4, -1, -1, 0, 1, 2]`

For `i = 1`, the fixed number is `-1`:

| Fixed value | `num[j]` | `num[k]` | Sum | Action |
|---:|---:|---:|---:|---|
| -1 | -1 | 2 | 0 | Save `[-1, -1, 2]`; move both pointers |
| -1 | 0 | 1 | 0 | Save `[-1, 0, 1]`; move both pointers |

When the loop reaches the second `-1) as the fixed value, the duplicate check skips it.

**Final output:** `[[-1, -1, 2], [-1, 0, 1]]`

## Complexity

- **Time:** `O(n^2)` — sorting is `O(n log n)`; the outer loop runs `O(n)` times and the two-pointer scan is `O(n)` per iteration.
- **Auxiliary space:** Sorting may use `O(log n)` stack space; the two-pointer scan uses `O(1)` extra space, excluding the output. The answer itself can contain multiple triplets.

## Edge Cases

- **Fewer than three numbers:** No triplet can be formed.
- **All numbers positive or all numbers negative:** No triplet can sum to zero unless the array includes suitable positive/negative values or zeros.
- **Repeated values:** Skip duplicates for `i`, `j`, and `k` to keep the result unique.
- **Zeros:** Three zeros form a valid triplet when at least three zeros are present.
