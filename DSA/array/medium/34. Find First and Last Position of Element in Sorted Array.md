# 34. Find First and Last Position of Element in Sorted Array

**LeetCode:** https://leetcode.com/problems/find-first-and-last-position-of-element-in-sorted-array/

## Problem

Given a sorted array `nums` and a target, return the starting and ending indices of the target's range. If the target is not present, return `[-1, -1]`.

### Example

```text
Input: nums = [1, 2, 2, 2, 5, 7], target = 2
Output: [1, 3]
```

## Approach: Binary Search with STL

Because the array is sorted, use C++ binary-search algorithms:

1. `binary_search()` checks whether the target exists.
2. `lower_bound()` finds the first element greater than or equal to the target.
3. `upper_bound()` finds the first element strictly greater than the target.
4. Convert iterators to indices by subtracting `nums.begin()`.
5. The last target index is the `upper_bound()` index minus one.

## C++ Solution

```cpp
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        vector<int> result;

        if (binary_search(nums.begin(), nums.end(), target)) {
            auto l = lower_bound(nums.begin(), nums.end(), target);
            auto u = upper_bound(nums.begin(), nums.end(), target);

            int index = l - nums.begin();
            int lastindex = u - nums.begin();

            result.push_back(index);
            result.push_back(lastindex - 1);
            return result;
        } else {
            result.push_back(-1);
            result.push_back(-1);
            return result;
        }
    }
};
```

## Dry Run

Input: `nums = [1, 2, 2, 2, 5, 7]`, `target = 2`

| Step | Operation | Value |
|---|---|---|
| 1 | `binary_search(..., 2)` | `true` |
| 2 | `lower_bound(..., 2)` | Iterator at index `1` |
| 3 | `index = l - nums.begin()` | `1` |
| 4 | `upper_bound(..., 2)` | Iterator at index `4` (value `5`) |
| 5 | `lastindex = u - nums.begin()` | `4` |
| 6 | Last occurrence = `lastindex - 1` | `3` |
| 7 | Return result | `[1, 3]` |

### Why subtract one?

`upper_bound()` points to the first element **greater than** the target, not the last target occurrence. Moving back one index gives the final occurrence.

## Complexity

- **Time:** `O(log n)` — each STL search is logarithmic.
- **Auxiliary space:** `O(1)` — the result always contains two integers.

## Edge Cases

- Target absent: return `[-1, -1]`.
- One matching element: both indices are equal.
- All elements equal to target: return `[0, nums.size() - 1]`.
- Empty array: `binary_search()` returns false, so the result is `[-1, -1]`.
