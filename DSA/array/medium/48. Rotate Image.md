# 48. Rotate Image

- **LeetCode:** [48. Rotate Image](https://leetcode.com/problems/rotate-image/)
- **Difficulty:** Medium
- **Category:** Arrays / 2D Matrix
- **Pattern:** Transpose + Reverse Rows

## 1. Question

You are given an n x n 2D matrix representing an image. Rotate the image by **90 degrees clockwise**.

You must rotate the matrix **in place**, meaning you must modify the input matrix directly. Do not create another matrix for the rotated result.

**Example**

Input:

~~~text
matrix = [[1,2,3],
          [4,5,6],
          [7,8,9]]
~~~

Output:

~~~text
[[7,4,1],
 [8,5,2],
 [9,6,3]]
~~~

## 2. Solution Approach

| Step | What to do | Why it works |
|---|---|---|
| 1. Transpose | Swap matrix[i][j] with matrix[j][i] for elements above the main diagonal. | Rows become columns. |
| 2. Reverse rows | Reverse each row using reverse(matrix[i].begin(), matrix[i].end()). | Converts the transposed matrix into a 90° clockwise rotation. |

### Why start the inner loop at j = i + 1?

This skips diagonal elements and prevents swapping each pair twice. For example, after swapping matrix[0][1] with matrix[1][0], we must not swap that pair again.

## 3. C++ Solution

~~~cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();

        // Step 1: Transpose the matrix
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(matrix[i][j], matrix[j][i]);
            }
        }

        // Step 2: Reverse every row
        for (int i = 0; i < n; i++) {
            reverse(matrix[i].begin(), matrix[i].end());
        }
    }
};
~~~

## 4. Code Explanation

| Code | Explanation |
|---|---|
| int n = matrix.size(); | Gets the number of rows. Since the matrix is square, it is also the number of columns. |
| for (int i = 0; i < n; i++) | Visits each row during transposition. |
| for (int j = i + 1; j < n; j++) | Visits only elements above the main diagonal. |
| swap(matrix[i][j], matrix[j][i]); | Swaps a position with its mirrored position across the main diagonal. |
| reverse(matrix[i].begin(), matrix[i].end()); | Reverses the current row in place. |
| void rotate(vector<vector<int>>& matrix) | Uses a reference, so changes are made directly to the original matrix. No matrix is returned. |

## 5. Dry Run

Input:

~~~text
[[1,2,3],
 [4,5,6],
 [7,8,9]]
~~~

### Step A: Transpose

| Swap | Matrix after swap |
|---|---|
| matrix[0][1] ↔ matrix[1][0] | [[1,4,3],[2,5,6],[7,8,9]] |
| matrix[0][2] ↔ matrix[2][0] | [[1,4,7],[2,5,6],[3,8,9]] |
| matrix[1][2] ↔ matrix[2][1] | [[1,4,7],[2,5,8],[3,6,9]] |

### Step B: Reverse every row

| Row | Before | After |
|---|---|---|
| 0 | [1,4,7] | [7,4,1] |
| 1 | [2,5,8] | [8,5,2] |
| 2 | [3,6,9] | [9,6,3] |

Final matrix:

~~~text
[[7,4,1],
 [8,5,2],
 [9,6,3]]
~~~

## 6. Key Insight to Remember

> **90° clockwise rotation = Transpose + Reverse every row.**

Transpose swaps rows and columns; reversing each row completes the clockwise rotation.

## 7. Complexity

- **Time:** O(n²) — transposition and row reversals each process up to n² elements.
- **Auxiliary space:** O(1) — the matrix is modified in place, using only a constant amount of extra space.

## 8. Edge Cases

| Case | Expected behavior |
|---|---|
| 1 x 1 matrix | The single element remains unchanged. |
| 2 x 2 matrix | Both steps produce the correct clockwise rotation. |
| Matrix with repeated values | The same operations work; values do not need to be unique. |

**Important:** The problem guarantees a non-empty square matrix.
