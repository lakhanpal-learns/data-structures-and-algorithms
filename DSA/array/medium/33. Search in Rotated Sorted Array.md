# 33. Search in Rotated Sorted Array

**LeetCode:** 33  
**Difficulty:** Medium  
**Topic:** Binary Search  
**Progress:** Practiced linear-search approach; optimized binary-search approach documented below.

## 1. Problem

Given an integer array `nums` that was originally sorted in ascending order but then rotated at an unknown pivot, return the index of `target`. Return `-1` if the target is not present.

Assume all values in `nums` are distinct.

**Example**

```text
Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4
```

## 2. First approach: Linear Search

The first solution checks each element from left to right until the target is found.

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int i = 0;

        while (i < nums.size()) {
            if (nums[i] == target) {
                return i;
            } else {
                i++;
            }
        }

        return -1;
    }
};
```

### Logic in plain English

1. Start at index `0`.
2. Compare the current element with `target`.
3. If they match, return the current index immediately.
4. Otherwise, move to the next index.
5. If the loop finishes without a match, return `-1`.

| Complexity | Cost |
|---|---|
| Time | `O(n)` — in the worst case, every element is checked |
| Extra space | `O(1)` |

This approach is correct, but it does not use the sorted structure of the rotated array. Binary search improves the time complexity to `O(log n)`.

## 3. Optimized approach: Modified Binary Search

At every iteration, calculate the middle index. Because the array was sorted and rotated, **at least one half of the current search range is sorted**.

- If `nums[mid] == target`, return `mid`.
- If the **left half is sorted** (`nums[left] <= nums[mid]`), check whether the target lies within that half. If it does, move `right` to `mid - 1`; otherwise, move `left` to `mid + 1`.
- Otherwise, the **right half is sorted**. Check whether the target lies within it. If it does, move `left` to `mid + 1`; otherwise, move `right` to `mid - 1`.
- If the search range becomes empty, return `-1`.

## 4. C++ solution

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size() - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            // Left half is sorted.
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            }
            // Otherwise, the right half is sorted.
            else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }

        return -1;
    }
};
```

## 5. Code explanation

| Code | Meaning |
|---|---|
| `left = 0` | Start at the first index. |
| `right = nums.size() - 1` | Start at the last index. |
| `left <= right` | Continue while the search range is not empty. |
| `mid = left + (right - left) / 2` | Find the middle index safely. |
| `nums[mid] == target` | The target is found; return its index. |
| `nums[left] <= nums[mid]` | The left half is sorted. |
| `nums[left] <= target && target < nums[mid]` | The target fits inside the sorted left half, so discard the right half. |
| `nums[mid] < target && target <= nums[right]` | The target fits inside the sorted right half, so discard the left half. |
| `return -1` | The target is absent. |

## 6. Dry run

Input: `nums = [4,5,6,7,0,1,2]`, `target = 0`

| Step | left | right | mid | nums[mid] | Decision |
|---:|---:|---:|---:|---:|---|
| 1 | 0 | 6 | 3 | 7 | Left half `[4,5,6,7]` is sorted. Target 0 is not in its range, so set `left = 4`. |
| 2 | 4 | 6 | 5 | 1 | Left half `[0,1]` is sorted. Target 0 is in its range, so set `right = 4`. |
| 3 | 4 | 4 | 4 | 0 | Target found; return index `4`. |

## 7. Key insight to remember

**Find the sorted half first, then check whether the target belongs to that half.** Keep that half if it can contain the target; otherwise, discard it. This lets binary search eliminate about half the remaining range each iteration.

## 8. Complexity

- **Time:** `O(log n)`
- **Extra space:** `O(1)`

## 9. Edge cases

- Target is the first element.
- Target is the last element.
- Target is not present.
- Array has one element.
- Array is rotated by one position or not rotated.
- Empty array: the loop is skipped and the function returns `-1`.
