# 31. Next Permutation

**LeetCode:** [31. Next Permutation](https://leetcode.com/problems/next-permutation/)  
**Difficulty:** Medium  
**Topics:** Array, Two Pointers, Greedy

## Problem

Given an array of integers, rearrange it into the next lexicographically greater permutation. If no greater permutation exists, rearrange it into the lowest possible order (ascending order).

The rearrangement must be in-place and use only constant extra space.

### Examples

**Example 1**

Input: `nums = [1,2,3]`  
Output: `[1,3,2]`

**Example 2**

Input: `nums = [3,2,1]`  
Output: `[1,2,3]`

**Example 3**

Input: `nums = [1,1,5]`  
Output: `[1,5,1]`

## Approach: Pivot, Successor, Swap, Reverse

We need the next permutation that is greater than the current array, but as small as possible.

1. **Find the pivot:** Start at the second-last element and move left while `nums[i] >= nums[i + 1]`. The first position that breaks this descending order is the pivot.
2. **Find the successor:** If a pivot exists, scan from the right to find the first number greater than `nums[i]`.
3. **Swap:** Swap the pivot with its successor.
4. **Reverse the suffix:** Reverse all elements after the pivot. The suffix was descending, so reversing it makes it ascending and therefore as small as possible.
5. If no pivot exists (`i == -1`), the entire array is descending. Reversing the whole array produces the lowest permutation.

## C++ Solution

```cpp
class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        int n = nums.size();

        // Step 1: Find the pivot
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }

        // Step 2: Find the successor and swap
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }

            swap(nums[i], nums[j]);
        }

        // Step 3: Reverse the suffix (or the whole array if no pivot)
        reverse(nums.begin() + i + 1, nums.end());
    }
};
```

## Code Explanation

| Code | Meaning |
|---|---|
| `int i = n - 2` | Start from the second-last index because we compare each element with the next one. |
| `nums[i] >= nums[i + 1]` | The pair is descending or equal, so continue moving left. |
| `i >= 0` | Confirms a pivot was found. If false, the entire array is non-increasing. |
| `int j = n - 1` | Start searching for the successor from the right. |
| `nums[j] <= nums[i]` | Skip values that are not strictly greater than the pivot. |
| `swap(nums[i], nums[j])` | Make the permutation greater with the smallest possible increase. |
| `reverse(nums.begin() + i + 1, nums.end())` | Put the suffix in ascending order to get the smallest possible result. |

## Dry Run

Input: `[1, 3, 5, 4, 2]`

| Step | Action | Array |
|---|---|---|
| 1 | Scan from the right: `5 > 4`, so keep moving left; `3 < 5`, so pivot is `3` at index 1. | `[1, 3, 5, 4, 2]` |
| 2 | Search from the right; `2` is not greater than 3, but `4` is. Successor is 4. | `[1, 3, 5, 4, 2]` |
| 3 | Swap pivot 3 with successor 4. | `[1, 4, 5, 3, 2]` |
| 4 | Reverse the suffix after index 1: `[5, 3, 2]` becomes `[2, 3, 5]`. | `[1, 4, 2, 3, 5]` |

**Final output:** `[1, 4, 2, 3, 5]`

## Edge Cases

- **Only one element:** Nothing changes.
- **Already descending:** `[3,2,1]` becomes `[1,2,3]`.
- **Duplicates:** `[1,1,5]` becomes `[1,5,1]`; use `>=` while finding the pivot and `<=` while finding the successor.
- **Empty array:** The operations are safe for an empty vector in this implementation, since `i` becomes `-2` and the reverse range is empty.

## Complexity

- **Time:** `O(n)` — the pivot search, successor search, and reversal each take at most linear time.
- **Auxiliary space:** `O(1)` — rearrangement is done in-place.

## Key Insight

The suffix to the right of the pivot is in descending order. Swap the pivot with the rightmost element greater than it, then reverse the suffix. This creates the smallest permutation that is greater than the original one.
