# 56. Merge Intervals

**LeetCode:** [56. Merge Intervals](https://leetcode.com/problems/merge-intervals/)  
**Difficulty:** Medium  
**Pattern:** Sorting + intervals

## 1. Problem

Given an array of intervals where `intervals[i] = [start_i, end_i]`, merge all overlapping intervals and return an array of the non-overlapping intervals that cover all the original intervals.

### Example

**Input**
```cpp
intervals = {{1, 3}, {2, 6}, {8, 10}, {15, 18}};
```

**Output**
```cpp
{{1, 6}, {8, 10}, {15, 18}}
```

Explanation: `[1, 3]` and `[2, 6]` overlap, so they merge into `[1, 6]`. The other intervals do not overlap with this merged interval or each other.

## 2. Approach

1. **Sort** intervals by their starting points. This lets us process them from left to right.
2. If the input is empty, return an empty result.
3. Add the first interval to the result. It becomes the interval we compare against next.
4. For every later interval, compare its start with the end of the last interval in the result:
   - If `current[0] <= result.back()[1]`, they overlap. Update the last result interval's end with `max(result.back()[1], current[1])`.
   - Otherwise, there is no overlap, so append the current interval to the result.
5. Return the result.

Because intervals are sorted by start, the current interval cannot start before the last result interval. We only need to check whether its start is at or before the last interval's end.

## 3. C++ Solution

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) {
            return {};
        }

        sort(intervals.begin(), intervals.end());

        vector<vector<int>> result;
        result.push_back(intervals[0]);

        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] <= result.back()[1]) {
                result.back()[1] =
                    max(result.back()[1], intervals[i][1]);
            } else {
                result.push_back(intervals[i]);
            }
        }

        return result;
    }
};
```

## 4. Code Explanation

| Code | Meaning |
|---|---|
| `intervals.empty()` | Handles an empty input safely. |
| `sort(intervals.begin(), intervals.end())` | Sorts intervals by start; ties are ordered by the next value. |
| `result.push_back(intervals[0])` | Starts the result with the first interval. |
| `intervals[i][0]` | Start of the current interval. |
| `result.back()[1]` | End of the last interval currently in the result. |
| `intervals[i][0] <= result.back()[1]` | Checks whether the current interval overlaps or touches the last result interval. |
| `max(result.back()[1], intervals[i][1])` | Keeps the farther ending point while merging. |
| `result.push_back(intervals[i])` | Stores a separate interval when there is no overlap. |

### Understand `back()`

`result.back()` returns the **last interval** in the result.

For example, if `result = {{1, 6}, {8, 10}}`, then `result.back()` is `{8, 10}`, and `result.back()[1]` is `10`.

## 5. Dry Run

Input after sorting:

```cpp
{{1, 3}, {2, 6}, {8, 10}, {15, 18}}
```

| Current interval | Last interval in result | Check | Action | Result |
|---|---|---|---|---|
| Start with `[1, 3]` | — | — | Add first interval | `[[1, 3]]` |
| `[2, 6]` | `[1, 3]` | `2 <= 3` → true | Merge; end becomes `max(3, 6) = 6` | `[[1, 6]]` |
| `[8, 10]` | `[1, 6]` | `8 <= 6` → false | Append separately | `[[1, 6], [8, 10]]` |
| `[15, 18]` | `[8, 10]` | `15 <= 10` → false | Append separately | `[[1, 6], [8, 10], [15, 18]]` |

**Final output:** `[[1, 6], [8, 10], [15, 18]]`

## 6. Important Cases

### Overlapping intervals

`[1, 5]` and `[3, 7]` merge into `[1, 7]`.

### One interval inside another

`[1, 10]` and `[3, 5]` merge into `[1, 10]`. The end remains `max(10, 5) = 10`.

### Touching endpoints

`[1, 3]` and `[3, 5]` merge into `[1, 5]`, because the condition uses `<=`.

### No overlap

`[1, 3]` and `[4, 6]` stay separate because `4 <= 3` is false.

## 7. Key Insight

After sorting, compare each interval only with the **last interval in the result**:

- **Overlap:** extend the last interval's end using `max()`.
- **No overlap:** append the current interval.

Remember: `current[0] <= result.back()[1]` is the overlap check, and `max()` prevents the merged end from moving backward.

## 8. Complexity

- **Time:** `O(n log n)` for sorting, plus `O(n)` for the scan; overall `O(n log n)`.
- **Auxiliary space:** depends on the sorting implementation (typically `O(log n)` stack space for introsort).
- **Output space:** up to `O(n)` for the result vector.
