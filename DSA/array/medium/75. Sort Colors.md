# LeetCode 75 — Sort Colors

**Difficulty:** Medium  
**Topics:** Array, Two Pointers, Dutch National Flag Algorithm

## 1. Question

Given an integer array `nums` containing only `0`, `1`, and `2`, sort the array in-place so that all `0`s come first, followed by all `1`s, and then all `2`s. Do not use a library sorting function.

**Example**

Input: `nums = [2,0,2,1,1,0]`  
Output: `[0,0,1,1,2,2]`

Another dry-run example: `[2,2,0,1]` becomes `[0,1,2,2]`.

## 2. Solution Approach

| Pointer | Meaning |
|---|---|
| `low` | Boundary for the next `0`; everything before it is confirmed `0`. |
| `mid` | Current element to inspect. |
| `high` | Boundary for the next `2`; everything after it is confirmed `2`. |

| Condition | Action | Reason |
|---|---|---|
| `nums[mid] == 0` | Swap `nums[low]` and `nums[mid]`; increment `low` and `mid`. | Put `0` in the left region. The incoming value at `mid` is already from the processed middle region (or `low == mid`). |
| `nums[mid] == 1` | Increment `mid`. | `1` belongs in the middle region, so it is already in the right place. |
| `nums[mid] == 2` | Swap `nums[mid]` and `nums[high]`; decrement `high` only. | Put `2` in the right region. The value swapped into `mid` has not been checked, so inspect it before advancing. |

Initialize `low = 0`, `mid = 0`, and `high = nums.size() - 1`. Start `mid` at zero because every element is initially unprocessed. Continue while `mid <= high`.

## 3. C++ Solution

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int low = 0;
        int mid = 0;
        int high = nums.size() - 1;

        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums[low], nums[mid]);
                low++;
                mid++;
            }
            else if (nums[mid] == 1) {
                mid++;
            }
            else {
                swap(nums[mid], nums[high]);
                high--;
            }
        }
    }
};
```

## 4. Code Explanation

| Code | Explanation |
|---|---|
| `int low = 0;` | Start the zero boundary at the first index. |
| `int mid = 0;` | Begin inspecting at the first element because none have been processed. |
| `int high = nums.size() - 1;` | Start the two boundary at the last index. |
| `while (mid <= high)` | Process while the unknown region is not empty. |
| `if (nums[mid] == 0)` | The current value belongs on the left. |
| `swap(nums[low], nums[mid]); low++; mid++;` | Move the zero to the left and advance both pointers. |
| `else if (nums[mid] == 1)` | The current value belongs in the middle; increment `mid`. |
| `else` | The current value is `2`, so swap it with the rightmost unchecked position. |
| `swap(nums[mid], nums[high]); high--;` | Put the `2` on the right. Keep `mid` unchanged because the incoming value is still unchecked. |

## 5. Dry Run

Input: `[2,2,0,1]`

| Step | `low` | `mid` | `high` | `nums[mid]` | Action | Array after action |
|---|---:|---:|---:|---:|---|---|
| Initial | 0 | 0 | 3 | 2 | Initialize pointers | `[2,2,0,1]` |
| 1 | 0 | 0 | 2 | 2 | Swap indices 0 and 3; decrement `high` | `[1,2,0,2]` |
| 2 | 0 | 0 | 2 | 1 | Increment `mid` | `[1,2,0,2]` |
| 3 | 0 | 1 | 2 | 2 | Swap indices 1 and 2; decrement `high` | `[1,0,2,2]` |
| 4 | 0 | 1 | 1 | 0 | Swap indices 0 and 1; increment `low` and `mid` | `[0,1,2,2]` |
| Stop | 1 | 2 | 1 | — | `mid > high`, so stop | `[0,1,2,2]` |

**Why does `mid` stay unchanged when processing `2`?** The swap brings an unchecked value from the right into `mid`. It could be `0`, `1`, or `2`, so it must be inspected next.

## 6. Key Insight to Remember

**0 → swap left, increment `low` and `mid`; 1 → increment `mid`; 2 → swap right, decrement `high` only.** When swapping with `high`, recheck `mid` because the incoming value is unknown.

## 7. Complexity

- **Time:** `O(n)` — each pointer moves across the array at most linearly.
- **Extra space:** `O(1)` — sorting is done in-place.

## 8. Edge Cases

| Input | Expected output | Reason |
|---|---|---|
| `[0]` | `[0]` | Single element. |
| `[2,1,0]` | `[0,1,2]` | Reverse order. |
| `[0,0,0]` | `[0,0,0]` | All values are zero. |
| `[1,1,1]` | `[1,1,1]` | All values are one. |
| `[2,2,2]` | `[2,2,2]` | All values are two. |
| `[2,2,0,1]` | `[0,1,2,2]` | Rechecks swapped-in values correctly. |
