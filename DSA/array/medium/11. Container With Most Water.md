# 11. Container With Most Water

**LeetCode:** https://leetcode.com/problems/container-with-most-water/  
**Difficulty:** Medium  
**Pattern:** Two Pointers

## Question

You are given an integer array `height`. Each element represents the height of a vertical line at its index. Choose two lines that, together with the x-axis, form a container that holds the most water.

Return the maximum amount of water the container can hold.

**Example**

```text
Input:  height = [1,8,6,2,5,4,8,3,7]
Output: 49
```

The best pair is at indices `1` and `8`: the width is `8 - 1 = 7`, the limiting height is `min(8, 7) = 7`, and the area is `7 * 7 = 49`.

## Solution Approach

Use the **two-pointer technique**. Start one pointer at the beginning and the other at the end of the array. Calculate the area between them, update the best area, and move the pointer at the shorter line inward.

The area is:

```text
area = (right - left) * min(height[left], height[right])
```

Why move the shorter line? The shorter line limits the water height. Moving the taller line inward only reduces the width while the shorter line still limits the height, so it cannot improve the area for that fixed shorter line. Moving the shorter pointer gives us a chance to find a taller boundary.

## C++ Code

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int a = 0;
        int left = 0;
        int right = height.size() - 1;

        while (left < right) {
            int width = right - left;
            int min_height;

            if (height[left] < height[right]) {
                min_height = height[left];
            } else {
                min_height = height[right];
            }

            int area = width * min_height;

            if (area > a) {
                a = area;
            }

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return a;
    }
};
```

## Code Explanation

| Code | Explanation |
|---|---|
| `int a = 0;` | Stores the largest area found so far. |
| `int left = 0;` | Starts the left pointer at the first index. |
| `int right = height.size() - 1;` | Starts the right pointer at the last index. |
| `while (left < right)` | Continues while the pointers select two different lines. |
| `int width = right - left;` | Calculates the horizontal distance between the lines. |
| The `if/else` that sets `min_height` | Finds the shorter line, because water cannot be higher than the shorter boundary. |
| `int area = width * min_height;` | Calculates the water area for the current pair. |
| `if (area > a) a = area;` | Saves the area if it is the best one seen so far. |
| The final `if/else` | Moves the pointer at the shorter line inward. If the heights are equal, this code moves `right`. |
| `return a;` | Returns the maximum area found. |

## Dry Run

Input: `height = [1,8,6,2,5,4,8,3,7]`

| Left index | Right index | Heights | Width | Area | Best area | Pointer moved |
|---:|---:|---|---:|---:|---:|---|
| 0 | 8 | 1, 7 | 8 | 8 | 8 | `left++` |
| 1 | 8 | 8, 7 | 7 | 49 | 49 | `right--` |
| 1 | 7 | 8, 3 | 6 | 18 | 49 | `right--` |
| 1 | 6 | 8, 8 | 5 | 40 | 49 | `right--` |
| 1 | 5 | 8, 4 | 4 | 16 | 49 | `right--` |
| 1 | 4 | 8, 5 | 3 | 15 | 49 | `right--` |
| 1 | 3 | 8, 2 | 2 | 4 | 49 | `right--` |
| 1 | 2 | 8, 6 | 1 | 6 | 49 | `right--` |

**Final output:** `49`

## Key Insight to Remember

**Calculate the area, save the maximum, then move the shorter boundary.** Moving both pointers or always moving the taller boundary would miss the reasoning that makes this approach work.

## Complexity

- **Time:** `O(n)` — each pointer moves inward at most `n - 1` times combined.
- **Auxiliary space:** `O(1)` — only a fixed number of variables are used.

## Edge Cases

- **Two lines:** Only one container can be formed.
- **Equal heights:** Either pointer can move; this implementation moves the right pointer.
- **A short boundary:** It limits the area even if the other line is very tall.
