# Coding Interview Tips

Before Coding

- Clarify the problem.
- Ask questions if requirements are unclear.
- Think of brute force first.

During Coding

- Write clean code.
- Use meaningful variable names.
- Handle edge cases.

After Coding

- Dry Run
- Optimize if possible.
- Explain Time Complexity.
- Explain Space Complexity.

---

# Edge Cases

- Empty Input
- Single Element
- Duplicate Values
- Negative Numbers
- Large Inputs
